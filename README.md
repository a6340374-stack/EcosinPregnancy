# alinaecosin.ru — сайт Алины Сингизовой

Сайт-визитка нутрициолога: главная страница и магазин. Статика, без сборщика и
зависимостей — что лежит в репозитории, то и отдаётся браузеру.

**Пуш в `main` выкатывает сайт на боевой домен.** GitHub Pages публикует эту
ветку напрямую, изменения видны на alinaecosin.ru примерно через минуту.
Отдельного шага деплоя нет, ветки-стейджинга нет. Домен привязан файлом
`CNAME` — не удалять и не переименовывать.

Имя репозитория `EcosinPregnancy` осталось от самой первой версии и текущему
содержимому не соответствует. Не путать с «Диспетчерской» — это отдельный
сервис на alinaecosin.store, который принимает заявки с формы и отдаёт каталог
магазина; живёт он в другом репозитории.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | главная целиком: разметка, стили и скрипты в одном файле |
| `shop.html` | магазин: обёртка, статический каталог и подключение виджета |
| `img/` | изображения в WebP |
| `tools/build_shop.py` | сборка статического каталога, см. `tools/README.md` |
| `robots.txt` | правила обхода, отдельная секция для Яндекса |
| `sitemap.xml` | карта сайта |
| `og-image.jpg` | превью для соцсетей, 1200×630 |
| `CNAME` | привязка домена |
| `08e118f4….txt` | ключ IndexNow, должен отдаваться по прямой ссылке |

## Каталог магазина обновляется руками

Товары рисует виджет с alinaecosin.store. Робот Яндекса плохо исполняет
JavaScript, поэтому внутри `#ecosin-shop` лежит статическая копия каталога:
её видит поиск, а живому посетителю `widget.js` подменяет её на интерактивную
версию с корзиной.

Эта копия **не обновляется сама**. После любого изменения цен, остатков или
состава каталога:

```
python tools/build_shop.py
git add -A && git commit -m "Обновлён каталог" && git push
```

Скрипт перезаписывает блоки между маркерами `SHOP:STATIC` и `SHOP:JSONLD`
и проставляет свежий `lastmod` в `sitemap.xml`. Руками внутри маркеров ничего
не писать — перезатрётся.

## Правила, которые легко нарушить по незнанию

**Не зашивать картинки в HTML через `data:base64`.** Так главная весила 796 КБ,
не кэшировалась и блокировала разбор страницы. Новые изображения — файлом в
`img/`, в WebP, с атрибутами `width`, `height` и `loading="lazy"` всем, кроме
первой картинки на экране.

**Не возвращать в `robots.txt` директивы `Host` и `Crawl-delay`** — Яндекс их
не поддерживает с 2018 года. Параметры ссылок склеиваются через `Clean-param`,
а не прячутся через `Disallow`: запрет обхода не передаёт вес на чистый адрес.

**Не писать ключевые слова в текст «для поиска».** В Яндексе переоптимизация
наказывается жёстче, чем недооптимизация: SEO-простыни в подвале и ключи в
точном вхождении ведут под фильтр Баден-Баден.

**Разметка Schema.org должна соответствовать тому, что видно на странице.**
Цены и наличие в JSON-LD берутся из того же API, что и каталог, — руками их
не править.

## Состояние SEO

Сделано: статический каталог с разметкой `Product` для 20 товаров, картинки
вынесены из HTML (главная 793 КБ → 79 КБ), `robots.txt` с `Clean-param`,
подключён IndexNow.

Не сделано:

- **Яндекс.Метрика не установлена** — счётчика на сайте нет вообще;
- **регион сайта в Яндекс.Вебмастере не задан** — без него сайт не участвует
  в локальной выдаче по запросам вроде «нутрициолог Уфа»;
- **на мобильном горизонтальная прокрутка** — кнопка «Записаться» в шапке
  выходит за экран примерно на 24 пикселя.
