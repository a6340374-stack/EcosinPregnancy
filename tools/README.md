# Служебные скрипты сайта

## build_shop.py — статический каталог для поиска

Каталог магазина рисует `widget.js` с alinaecosin.store. Робот Яндекса
исполняет JavaScript плохо, поэтому без сборки в исходном HTML `shop.html`
нет ни одного товара — поиск видит пустую страницу.

Скрипт тянет тот же API, что и виджет, и вклеивает в `shop.html`:

* карточки товаров внутри `#ecosin-shop` — их затирает `widget.js` при
  загрузке, живой посетитель видит обычный интерактивный магазин;
* разметку Schema.org (`ItemList` из `Product` с ценами и наличием) в `<head>`;
* сегодняшнюю дату в `lastmod` магазина в `sitemap.xml`.

Запускать **после каждого изменения каталога** — иначе в поиске останутся
старые цены:

```
python tools/build_shop.py
```

Скрипт правит файлы на месте и ничего не коммитит. Разметка вставляется между
маркерами `<!-- SHOP:STATIC:START -->` и `<!-- SHOP:JSONLD:START -->` —
руками внутри них ничего не писать, перезатрётся.

## IndexNow

Ключ лежит в корне: `08e118f44251689196925d14ab92159a.txt`. Файл должен
отдаваться по прямой ссылке и содержать ровно эту строку — не удалять.

Отправить страницы на переобход (один запрос покрывает Яндекс, Bing, Naver,
Seznam; Google в протоколе не участвует):

```
python <путь-к-плагину>/scripts/indexnow_submit.py \
  --host alinaecosin.ru \
  --key 08e118f44251689196925d14ab92159a \
  --key-location https://alinaecosin.ru/08e118f44251689196925d14ab92159a.txt \
  --urls https://alinaecosin.ru/ https://alinaecosin.ru/shop.html
```

Отправлять после деплоя, а не до: робот придёт на живую страницу.

## Картинки

Изображения лежат в `img/` в формате WebP. Внутрь HTML их больше не зашивать
через `data:base64` — так страница весила 796 КБ и не кэшировалась. Новую
картинку класть файлом в `img/`, ставить `width`, `height` и `loading="lazy"`
всем, кроме первой на экране.
