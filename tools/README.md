# Служебные скрипты сайта

## build.py — сборка страниц

Собирает статику в корне репозитория из исходников в `src/`. Нужен затем, что
шапка, меню, подвал и счётчик Метрики одинаковы на всех страницах, а править
их в пятнадцати файлах вручную никто не будет.

```
python tools/build.py            собрать всё
python tools/build.py --check    сверить корень с src/, ничего не записывая
```

`--check` возвращает код 1, если собранное не совпало с тем, что лежит в
корне. Это значит одно из двух: кто-то правил корень руками или забыли
пересобрать после правки `src/`.

Устройство и формат шапки параметров описаны в README репозитория, раздел
«Как собирается сайт». Коротко:

```
src/layouts/base.html   каркас, дырки вида {{ title }}
src/partials/*.html     шапка, подвал, Метрика, хвосты страниц
src/assets/*.css        стили, вклеиваются в <style> нужной страницы
src/pages/**/*.html     страницы: блок параметров между --- и содержимое
```

Заодно сборщик заново пишет `sitemap.xml` по полям `url`, `updated`,
`changefreq` и `priority` из шапок страниц. Руками карту сайта не трогать.

**Файлы в корне — результат сборки.** `index.html`, `shop.html`,
`legal/*.html` и `sitemap.xml` правке не подлежат: изменения теряются при
следующем запуске, молча и без предупреждения.

## Каталог магазина отключён

Страница магазина временно показывает уведомление. Виджет, карточки товаров,
схема Product и сборка каталога с сервера выключены. Не запускайте
`tools/build_shop.py`, пока магазин не будет восстановлен.

## IndexNow

Ключ лежит в корне: `08e118f44251689196925d14ab92159a.txt`. Файл должен
отдаваться по прямой ссылке и содержать ровно эту строку — не удалять.

Отправить страницы на переобход (один запрос покрывает Яндекс, Bing, Naver,
Seznam; Google в протоколе не участвует):

```
python <путь-к-плагину>/scripts/indexnow_submit.py \
  --host alinaecosin.ru \
  --key 08e118f44251689196925d14ab92159a \
  --key-location https://alinaecosin.ru/08e118f44251689196925d14ab92159a.txt \
  --urls https://alinaecosin.ru/ https://alinaecosin.ru/shop.html          https://alinaecosin.ru/legal/privacy.html          https://alinaecosin.ru/legal/offer.html          https://alinaecosin.ru/legal/disclaimer.html
```

Отправлять после деплоя, а не до: робот придёт на живую страницу.

## Картинки

Изображения лежат в `img/` в формате WebP. Внутрь HTML их больше не зашивать
через `data:base64` — так страница весила 796 КБ и не кэшировалась. Новую
картинку класть файлом в `img/`, ставить `width`, `height` и `loading="lazy"`
всем, кроме первой на экране.

## Чего в репозитории нет

Пакетов, `package.json`, `node_modules` и GitHub Actions. Всё, что нужно для
работы, — Python из стандартной поставки. Так деплой остаётся одним `git push`,
а сломаться может только то, что лежит в этой папке.
